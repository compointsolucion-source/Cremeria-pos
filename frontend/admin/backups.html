💾 Backups

⚠️ Importante sobre esta función: este botón descarga un archivo JSON con tus datos actuales (productos, clientes, tickets, turnos, inventario, configuración). No es un backup restaurable con un clic — si necesitas recuperar datos desde este archivo, requeriría reinsertarlos manualmente en la base de datos con ayuda técnica. Para restauración automática de los últimos cambios, Neon ya incluye un "point-in-time restore" de 6 horas en su plan gratuito, sin que tengas que hacer nada.

Exportar datos actuales

Se descargará un archivo .json con la información de tu sucursal. Las contraseñas nunca se incluyen.
