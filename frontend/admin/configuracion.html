🖥️ Impresoras de Windows (programa de escritorio)

Funciona con el modo "Impresora de Windows/Mac". Con una impresora (o la predeterminada de Windows) imprime directo, sin abrir ninguna ventana para elegir. Solo si eliges "Preguntar cada vez" se abre el diálogo de impresión.

🌐 Imprimir sin que pregunte (Chrome o Edge)

Un navegador normal siempre abre una ventana para elegir la impresora; por seguridad no se puede quitar desde la página. Para que imprima solo en tu impresora de Windows:

  1. En Windows, deja tu impresora de tickets como predeterminada (Configuración de Windows → Impresoras).
  2. Descarga el acceso directo de abajo y abre Compoint Punto siempre desde ahí.
  3. Entra con tu usuario y, en esa ventana, elige Impresora de Windows/Mac y guarda.

Si Chrome avisa que es un archivo .bat, es normal: elige "Conservar". Se abre en una ventana propia con su perfil: la primera vez tendrás que entrar con tu usuario y repetir el paso 3. Si prefieres no hacerlo, el programa de escritorio de Compoint Punto imprime directo sin nada de esto.

Conecta una báscula para leer el peso en vivo al pesar un producto en Mostrador, en vez de teclearlo a mano. Es opcional: si no la conectas, el teclado numérico sigue funcionando igual.

EstadoSin conectar

⚖️ 0.000 kg

ℹ️ ¿El peso no se lee bien?

No existe un solo protocolo que compartan todas las marcas de básculas. Esto funciona con la mayoría de básculas puestas en modo "salida continua" (revisa el manual de tu báscula para activarlo), pero puede necesitar ajustar la velocidad (baud rate) según el modelo real que conectes.

Si no sabes cuál usa tu báscula, deja 9600 e intenta conectar — es la más común en básculas comerciales. Si el peso se ve como símbolos o no aparece, prueba con otra. Siempre puedes seguir tecleándolo a mano.

🔖 Etiquetas PLU de la báscula 🏪 Todo el negocio

Si tu báscula imprime su propia etiqueta con código de barras (con el PLU del producto y el peso o precio), Mostrador y Caja pueden leerla directo con el lector y agregar el producto ya pesado, sin volver a pesarlo. El PLU debe coincidir exactamente con el "Código de barras" de ese producto en Compoint.

🏷️ Etiqueta final (bolsa) — tipo Torrey 🏪 Todo el negocio

Elige cómo se genera la etiqueta que se pega en la bolsa al final de pesar un producto. Automático: la propia báscula imprime su etiqueta (o no se usa etiqueta). Compoint imprime: se usa una impresora de etiquetas conectada. Esta opción aplica a todos los mostradores; la impresora de abajo es solo de este equipo.
