COMPOINT PUNTO PARA ESCRITORIO (Windows 10 y 11)
================================================

QUE ES
Un programa instalable (.exe) que abre el sistema del negocio en su propia
ventana, con el icono de Compoint, sin barra de direcciones. Ademas:
- Arranca solo al prender Windows (se puede desmarcar al instalar).
- Si cierras la ventana se queda en segundo plano (icono junto al reloj).
- Trae adentro el intermediario de impresion por red (puerto 3500):
  ya no hay que instalarlo aparte en esa computadora.
- Imprime por USB, Bluetooth o red igual que en Chrome, y ademas DIRECTO (sin
  dialogo) en cualquier impresora instalada en Windows (Configuracion del
  sistema -> Impresion de este dispositivo -> Impresoras de Windows).
- Como carga el sistema desde internet, SIEMPRE esta en la ultima version que
  publiques en "estable": no hay que reinstalar para actualizar.

COMO GENERAR EL INSTALADOR DE UN CLIENTE (lo haces tu, en GitHub)
1. Entra a tu repositorio en GitHub -> pestana "Actions".
2. A la izquierda elige "Instalador de escritorio (Windows)".
3. Clic en "Run workflow" y llena:
   - Direccion del sistema del cliente (ej. https://cliente1.onrender.com/login.html)
   - Nombre del negocio
4. Espera ~6 minutos. Al terminar, abre esa ejecucion y baja el archivo de
   "Artifacts" (Instalar-CompointPunto-<Negocio>.exe, viene dentro de un zip).
   Esos archivos se conservan 30 dias.
5. Pasale ese instalador al cliente.

Que hace GitHub por dentro (por si algun dia falla):
  a) Construye el instalador del programa con electron-builder
     (escritorio/dist/Payload-CompointPunto.exe). Es el "paquete".
  b) Compila la pantalla de Compoint (Go) -> escritorio/dist/instalador-base.exe
     (carpeta herramientas/instalador-escritorio).
  c) Pega el paquete al final de la pantalla y deja UN solo archivo:
     escritorio/dist/final/Instalar-CompointPunto-<Negocio>.exe
  Si el paso (b) o (c) falla, el flujo NO se rompe: entrega el instalador
  clasico de Windows (con la barra lateral de Compoint, en espanol, y que
  tambien deja elegir la carpeta del programa) con el mismo nombre. Se nota
  porque al abrirlo se ve el asistente gris de Windows y no el de Compoint.

COMO LO INSTALA EL CLIENTE
1. Doble clic en el instalador. Si Windows dice "Windows protegio su PC":
   "Mas informacion" -> "Ejecutar de todas formas" (aparece porque no tiene
   firma digital de paga; es normal. Algunos antivirus tambien lo revisan
   unos segundos la primera vez).
2. Se abre la ventana de Compoint con panel lateral:
   Bienvenida -> Tipo de instalacion -> Carpetas -> Instalando -> Listo.
3. Tipo de instalacion:
   - PREDETERMINADO (recomendado): no pregunta nada. Programa en
     %LOCALAPPDATA%\Programs\Compoint Punto, icono en escritorio, inicia con
     Windows. Sin permisos de administrador.
   - AVANZADO: pregunta para que se usara la computadora (Caja o Servidor
     del negocio), los accesos directos, "iniciar con Windows" y las carpetas.
4. Carpetas que se pueden elegir (solo en Avanzado):
   - Programa: donde se instala el programa. Si la carpeta elegida no se
     llama "Compoint Punto" el instalador agrega esa subcarpeta solo.
     Si se elige Archivos de programa, Windows pide permiso de administrador.
   - Informacion del negocio (base de datos): solo en modo Servidor. Por
     omision C:\CompointPunto\datos. Si ya existe una base de datos de
     Compoint en esta PC, la carpeta queda fija para no perder informacion.
   - Respaldos: por omision C:\CompointPunto\Respaldos, y opcionalmente una
     COPIA EXTRA en otra unidad (memoria USB o segundo disco). El instalador
     sugiere la USB si hay una conectada.
   Reglas: todo debe ir en un disco de la computadora (no USB ni red) salvo
   la copia extra; los respaldos no pueden quedar dentro del programa ni de
   la base de datos. El instalador avisa en rojo (no deja seguir) o en
   amarillo (deja seguir pero advierte, ej. "la copia extra esta en el mismo
   disco").
5. Al terminar, boton "Abrir Compoint Punto". Desde ese momento abre solo al
   prender Windows (si se dejo marcado).

Si generas el instalador SIN direccion, la primera vez pide la direccion del
sistema (y opcionalmente un usuario para entrar automatico).

COMO SE ENTREGAN LAS ELECCIONES AL PROGRAMA
El instalador no escribe la configuracion del programa: deja un archivo
%LOCALAPPDATA%\CompointPunto\instalacion.json con lo elegido (modo, carpetas,
iniciar con Windows). La PRIMERA vez que abre el programa lo lee, lo aplica y
lo borra (src/instalacion.js, aplicarInstalacion() en src/main.js). Para
probarlo sin instalar, se puede apuntar a otro archivo con la variable de
entorno COMPOINT_INSTALACION.

USO DIARIO
- F11: pantalla completa.   Ctrl+R / F5: recargar.   Ctrl +/-/0: zoom.
- Icono junto al reloj (clic derecho): Abrir, Pantalla completa, Recargar,
  Iniciar con Windows, Cambiar direccion o usuario, Salir por completo.
- Cerrar la ventana con la X NO cierra el programa (sigue en segundo plano
  para que otros equipos puedan imprimir fichas por red). Para cerrarlo del
  todo: clic derecho en el icono -> "Salir por completo".
- Impresoras USB/Bluetooth: se elige la impresora en una ventanita la primera
  vez; despues reconecta sola.
- Direccion para fichas por red en Configuracion del sistema:
  en esa misma PC  http://localhost:3500
  desde otros equipos  http://IP-DE-ESA-PC:3500

ENTRAR AUTOMATICO
En "Cambiar direccion o usuario" se puede guardar un usuario y contrasena.
Se guardan cifrados con la cuenta de Windows y entran solos UNA vez al abrir
el programa. Si alguien cierra sesion, la siguiente persona escribe la suya.
Usalo solo en equipos de una sola persona (cada cajero debe usar su usuario
para que su corte de caja sea suyo).

MODO SERVIDOR (trabajar sin internet)
- Instalar el MISMO instalador en la PC que sera el servidor y elegir
  Avanzado -> "Esta computadora sera el servidor del negocio". Despues, al
  abrir el programa, pide los datos del negocio y crea su propia base de datos
  local. No necesita internet para vender.
- Todo se guarda por omision en C:\CompointPunto  (datos\, Respaldos\,
  servidor.json, servidor-log.txt) o en las carpetas que se hayan elegido al
  instalar. NO borrar esas carpetas. En el panel del servidor, seccion
  "Donde se guarda todo", se ve cada ruta y se puede cambiar la copia extra.
- Esa PC debe estar encendida mientras se use el sistema.
- Las demas cajas: instalar el escritorio normal (Predeterminado) y poner la
  direccion que muestra el panel del servidor, ejemplo  http://192.168.1.50:3000
  (o abrirla en un navegador). Para impresoras USB/Bluetooth usar la app de
  escritorio, no el navegador.
- Al primer arranque Windows pregunta por el Firewall: elegir
  "Permitir acceso" en red privada, si no las otras cajas no se conectan.
- Panel del servidor: Ctrl+Alt+S o clic derecho en el icono junto al reloj.

SINCRONIZAR CON LA NUBE (sin entrar a Render)
- Panel del servidor -> "Sincronizar con la nube" -> "Conectar o cambiar la nube".
- Se escribe la direccion del sistema en la nube y el USUARIO Y CONTRASENA DEL
  DUENO (los mismos con los que se entra a ese sistema). Se usan una sola vez:
  la nube crea sola una clave, guarda solo su "hash" (tabla sync_vinculo) y se
  la entrega a este servidor, que la guarda cifrada. La contrasena no se guarda.
- Asi el cliente no necesita acceso a Render. Para que la nube sepa vincular,
  su servidor debe tener la migracion 006 (se aplica sola al publicar a
  "estable" y que Render termine de desplegar).
- Vincular otra vez (otra computadora, o reconectar) reemplaza la clave: la
  computadora anterior deja de subir. "Dejar de sincronizar" borra la clave en la nube.
- La primera copia deja a la nube como espejo del servidor, incluidos los
  usuarios: despues en la nube se entra con los usuarios del servidor.
- Alternativa manual (opciones avanzadas del panel): clave en la variable
  SYNC_KEY del servidor en Render. Sigue funcionando.

TRAER LA INFORMACION DE LA NUBE A LA COMPUTADORA (cliente que ya usa el sistema en internet)
- "Caja o equipo normal" SOLO ABRE la direccion de la nube en una ventana: la
  informacion se queda en la nube. Para tenerla en la computadora hay que
  usar "Servidor del negocio" y traerla.
- Primera vez: elegir "Servidor del negocio" -> "Ya tengo mi sistema en la
  nube" -> direccion + usuario y contrasena del DUENO -> "Conectar y revisar"
  (muestra cuantos productos, ventas, clientes y usuarios hay) -> "Traer mi
  informacion". Despues el dueno entra con los mismos usuario y contrasena.
- Si el equipo ya era servidor: Panel del servidor -> "Traer mi informacion de
  la nube a esta computadora". REEMPLAZA lo que haya (antes guarda un
  respaldo) y reinicia el programa.
- Se baja por pedazos y se escribe en una sola operacion: si falla (se va el
  internet, la nube esta dormida) no se guarda nada. En una computadora nueva la
  base queda vacia para volver a intentar; en una que ya tenia datos queda igual.
- Al terminar, la computadora queda como la PRINCIPAL: se vincula la
  sincronizacion (sin volver a copiar todo) y lo que se registre se sube a la
  nube, que queda como copia.
- Requisito: el sistema en la nube debe tener la actualizacion con las rutas
  /api/sync/exportar y /api/sync/licencia (se publica a "estable" y Render
  termina de desplegar). Si no, el programa avisa que falta actualizarlo.
- Seguro: al conectar la sincronizacion desde el panel, si la nube ya tiene
  informacion y esta computadora esta vacia, se DETIENE (conectar asi vaciaria
  la nube) y se indica usar "Traer mi informacion de la nube".

LICENCIA QUE SE TOMA DE LA NUBE (modo servidor)
- Al traer la informacion, o al conectar la sincronizacion con el usuario
  dueno, la computadora pide a la nube del cliente su licencia y la adopta: se
  quita la prueba de 30 dias. Se revisa de nuevo cada 6 horas y al abrir el
  programa (renovaciones). Necesita internet solo en ese momento.
- Con codigo firmado (CPT1-...) en la nube: es lo seguro; la firma se
  comprueba tambien en la computadora y debe ser del ID de ESA nube. Para eso
  la licencia de la nube se activa con el Activador igual que siempre.
- Licencia puesta a mano en la nube (sin codigo): se copia tipo, plan y fecha.
- Nube sin control de licencia (sistema propio de Compoint): la computadora
  queda sin prueba (permanente) y toma la licencia cuando la nube tenga una.
- Una licencia activada en la computadora con codigo propio no se baja por una
  igual o mas corta de la nube. Si la licencia de la nube ya vencio y aqui hay
  prueba vigente, se ignora.
- Ayuda -> "Mi servicio con Compoint" muestra cliente, estado, vigencia, plan
  y sucursales cuando el sistema detecta que ya es cliente (no sale en prueba).

LICENCIA Y PRUEBA DE 30 DIAS (modo servidor)
- La PRIMERA vez que abre el servidor de un cliente empieza sola una prueba de
  30 dias con el sistema completo. Arriba se ve cuantos dias quedan y los
  tickets salen con "VERSION DE PRUEBA". Todo lo capturado se conserva al contratar.
- Al terminar: modo "solo consulta" (ver reportes, exportar, respaldar; no
  registrar ventas). Con un codigo de activacion todo vuelve al instante.
- El codigo se pega en el sistema: Administracion -> Licencia. Funciona SIN
  internet y va ligado al ID de la computadora (el MachineGuid de Windows, por
  eso reinstalar el programa en la MISMA computadora no pide codigo nuevo).
  Cambiar de computadora si pide codigo nuevo.
- La licencia vive en la base de datos del servidor; las cajas que se conectan
  por red local usan la licencia del servidor (no necesitan codigo propio).
- Para que reinstalar no reinicie la prueba, el programa deja 2 o 3 archivos
  pequenos "lic.dat" fuera de la carpeta de datos:
    %LOCALAPPDATA%\CompointPunto   %APPDATA%\Compoint   %ProgramData%\Compoint
  (estan firmados por el propio programa; si se editan a mano se ignoran).
  Limite conocido: borrar la base de datos Y todos esos archivos reinicia la
  prueba. No es a prueba de todo; es para el uso normal.
- Si alguien atrasa el reloj de Windows, el sistema se queda con la fecha mas
  reciente que ya vio. Mas detalles: backend/scripts/LEEME-LICENCIA.txt
- La "llave publica" que comprueba los codigos va en
  backend/utils/licencia-clave-publica.js (la saca el Activador Compoint).
  Sin esa llave el programa funciona pero no acepta codigos.

RESPALDOS
- Al elegir "Salir por completo" se guarda un respaldo en la carpeta de
  respaldos (se conservan los ultimos 30).
- Tambien hay respaldo automatico cada 12 horas y boton "Respaldar ahora".
- COPIA EXTRA (otra unidad): cada respaldo se copia tambien alli. Si la unidad
  no esta conectada (USB desenchufada) el respaldo normal se hace igual y la
  copia queda pendiente; el panel lo avisa.
- Copia en la nube (Cloudinary): se configura en el panel con cloud name,
  api key y api secret. Se conservan los 10 dias mas recientes.
  Si no hay internet queda pendiente y se sube despues.
- Restaurar: desde el panel, elegir un respaldo. Antes de restaurar se guarda
  automaticamente un respaldo del estado actual.

ACTUALIZAR / REINSTALAR
Correr el instalador nuevo encima. El programa se reemplaza; los datos y
respaldos NO se tocan (el instalador detecta la base de datos existente y deja
esa carpeta fija). El instalador no deja continuar si Compoint Punto esta
abierto: pide cerrarlo (clic derecho en el icono junto al reloj -> Salir por
completo) y se puede reintentar sin empezar de nuevo.

DESINSTALAR
Configuracion de Windows -> Aplicaciones -> Compoint Punto -> Desinstalar.
Quita el programa y los accesos. La informacion del negocio y los respaldos
NO se borran (estan fuera de la carpeta del programa); si de verdad se quieren
eliminar hay que borrar esas carpetas a mano.

SI ALGO FALLA AL INSTALAR
La pantalla de error tiene "Reintentar" y el WhatsApp de soporte. El registro
queda en  %TEMP%\CompointInstalador\instalador-log.txt  (mandarlo a soporte).

PRUEBA MANUAL EN WINDOWS (hacerla una vez con cada instalador nuevo)
La pantalla del instalador se probo completa en modo simulado, pero lo que
toca Windows de verdad (discos, permisos, accesos directos) solo se puede ver
en una PC real. Checklist:
 1. Predeterminado: instala sin preguntar, icono en el escritorio, abre el
    programa, arranca con Windows.
 2. Avanzado + Caja: carpeta del programa en otro disco (ej. D:\); aparece
    D:\Compoint Punto con el .exe adentro; desmarcar "icono en el escritorio"
    -> no debe quedar el icono.
 3. Avanzado + Servidor con carpetas propias (datos en D:\, respaldos en D:\,
    copia extra en una USB): al abrir el programa y hacer el alta, la base de
    datos esta en la carpeta elegida; "Respaldar ahora" crea archivo en ambas.
 4. Reinstalar encima con el programa cerrado: no se pierde la base de datos,
    la carpeta de datos aparece fija.
 5. Reinstalar con el programa abierto: avisa que hay que cerrarlo; se cierra
    y "Reintentar" continua.
 6. Programa en Archivos de programa: Windows pide permiso (UAC); si se
    cancela, el instalador muestra el error y deja reintentar.
 7. Cerrar la ventana a media instalacion no corta la instalacion.

DESARROLLO
- Probar la app en tu PC:  cd escritorio, npm install, npm start
- Pruebas de la logica:  cd escritorio, node --test
- Archivos: src/main.js (ventana, bandeja, impresoras), src/intermediario.js,
  src/instalacion.js (lo que dejo el instalador), src/setup.html (primera
  configuracion), config-cliente.json (direccion), servidor/ (modo servidor).
- Instalacion asistida: package.json -> build.nsis (carpeta elegible,
  barra lateral build/instalador-lateral.bmp, espanol).
- Armado del instalador final: scripts/empaquetar-instalador.js.
- La pantalla de Compoint (Go) esta en herramientas/instalador-escritorio
  (ahi hay su propio LEEME.txt).
